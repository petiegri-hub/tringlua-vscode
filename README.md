# TriLingua

React + Vite alapú, magyar nyelvű nyelvtanuló prototípus német és angol fordításokkal.

## Követelmények
- Node.js LTS
- npm

## Fejlesztés
```bash
npm ci
npm run dev
```

Ezután nyisd meg a terminálban megjelenő címet (általában http://localhost:5173).

## Ellenőrzés és előnézet
```bash
npm run build
npm run preview
```

Az alkalmazás jelenleg 22 minta szót tartalmaz. A haladás számlálója a böngésző helyi tárhelyén tárolódik; a leckeszámok és napi célok demóadatok.
